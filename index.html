Empieza gratis

Tres pasos para usarla.

La extensión y el modelo se instalan por separado. Necesitas Chrome, llama.cpp y un modelo GGUF; recomendamos Qwen2.5 3B Instruct.

Leer la guía completa en GitHub ↗
  1. 1

    Descarga la extensión

    Baja el ZIP de Chrome y descomprímelo. La carpeta resultante debe contener manifest.json.

  2. 2

    Inicia tu modelo local

    Ejecuta llama-server en 127.0.0.1:8080 con un modelo GGUF. Puedes usar Qwen2.5 3B Instruct.

  3. 3

    Cárgala en Chrome

    Abre chrome://extensions/, activa el modo de desarrollador y selecciona Cargar extensión sin empaquetar.

Preguntas frecuentes

Lo que conviene saber.

¿Se necesita pagar o crear una cuenta?

No. El código y la instalación manual son gratuitos. Descargas llama.cpp y el modelo por separado, de acuerdo con sus respectivas licencias.

¿La extensión envía los mensajes automáticamente?

No. La respuesta de la IA se coloca en el borrador para que puedas revisarla, editarla y decidir si la envías.

¿Por qué necesito instalar un modelo?

La IA se ejecuta en tu propio equipo. La extensión se comunica con llama-server en 127.0.0.1:8080 y no incluye un modelo dentro del ZIP.

¿Puedo modificar el proyecto?

Sí. El repositorio incluye el código y acepta contribuciones mediante ramas y pull requests. Consulta la licencia BSD 3-Clause y el README antes de redistribuir cambios.
